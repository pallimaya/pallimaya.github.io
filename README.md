# Pallimaya — personal website

A single-page personal site built with plain HTML and CSS, hosted for free on GitHub Pages.

**Live site:** https://pallimaya.github.io/

## Files

| File | Purpose |
|---|---|
| `index.html` | The page content — hero, projects, about, contact |
| `styles.css` | All styling, including automatic light/dark mode |

## Editing

Everything is plain HTML and CSS — no build step, no dependencies. Edit `index.html`
for text and links, `styles.css` for colours and layout.

- **Contact email:** `index.html` currently has a placeholder (`your-email@example.com`).
  Replace both the `mailto:` link and the visible text in the Contact section.
- **Colours:** the whole palette lives in the `:root` block at the top of `styles.css`.
  Change `--accent` to re-theme the site.

Changes pushed to the `main` branch go live automatically within about a minute.
